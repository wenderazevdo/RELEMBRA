# Relembra (React + TypeScript + Supabase)
1. Supabase: crie um projeto, abra o SQL Editor e execute `supabase/migrations/0001_init.sql`.
2. Copie `.env.example` para `.env` e preencha URL e anon key (Project Settings → API).
3. `npm install` e `npm run dev`.
4. Cloudflare Pages (via GitHub): build `npm run build`, saída `dist`, e as duas variáveis VITE_ em Settings → Variables.
Estado: camada de dados, regras de estudo e SQL prontas; a interface completa (estudo, importação, resgate, mapa) ainda será portada do protótipo.
